## 1. 设计定位与原则

- **内容优先**：视频是全屏主角，UI  chrome 默认隐藏，点击才显形，3 秒无操作自动淡出。
- **深色沉浸**：App 强制深色（不跟随系统浅色），视频四周不出现白边白底。
- **克制精准**：一屏一个视觉焦点；阴影几乎不用（深色下用表面明度层次表达层级）；动效只传达"发生了什么"。
- **小白友好**：每个状态都有下一步指引；文案说人话（见 §7）。

参考基线：Material Design 3（色彩/动效）+ Apple HIG（触控尺寸/节奏），面向一加 Ace 6（6.83" / 165Hz / Android 16）。

## 2. 设计 Token（Flutter ThemeData 直接落地）

### 2.1 色彩（深色主题，值即 Flutter Color 十六进制）

| Token | 值 | 用途 |
| --- | --- | --- |
| `surface` | `#0B0B0F` | 页面最底层背景 |
| `surfaceContainer` | `#14141A` | 卡片、列表项、底部菜单 |
| `surfaceContainerHigh` | `#1F1F28` | 悬浮层、对话框、输入框底 |
| `onSurface` | `#F2F2F7` | 主文字/图标 |
| `onSurfaceVariant` | `#A6A6B3` | 次要文字（时间、计数、说明） |
| `primary` | `#FF4D6D` | 主操作、播放焦点、进度已播放、主按钮 |
| `onPrimary` | `#FFFFFF` | 主按钮上的文字 |
| `primaryContainer` | `#3A1622` |  tonal 按钮/选中态容器 |
| `secondary` | `#5BD3C8` | 下载中状态、链接类强调 |
| `tertiary` | `#FFC757` | 收藏激活态（金星） |
| `error` | `#FF6B6B` | 错误、删除确认 |
| `outline` | `#3A3A44` | 分割线、未播放进度底 |
| `outlineVariant` | `#26262F` | 卡片描边、禁用态 |
| `scrimTop / scrimBottom` | `#000000` 55%→0% / 0%→60% | 控制层上下渐变，保证白字可读 |

规则：一屏同时出现的颜色 ≤ 4 种（surface 系算一色）；红绿不混用表意（遵守国内习惯：涨红跌绿不适用于本 App，但"错误用红、完成用主色"即可，不用绿色表成功）。

### 2.2 字体与字阶（中文优先，不打包字体，用系统字体）

- 字体：系统默认（ColorOS 上中文渲染良好；不引 Web 字体，省包体）。
- 字阶（px / 行高 / 字重）：

| 名称 | 规格 | 用途 |
| --- | --- | --- |
| displaySmall | 36 / 1.15 / 600 | 空态大标题 |
| headlineSmall | 24 / 1.25 / 600 | 页面标题 |
| titleLarge | 20 / 1.3 / 600 | 视频文件名（列表/浮层） |
| titleMedium | 16 / 1.45 / 500 | 列表主文案、按钮 |
| bodyLarge | 16 / 1.5 / 400 | 输入框、正文 |
| bodyMedium | 14 / 1.45 / 400 | 次要说明 |
| labelLarge | 14 / 1.4 / 600 | 按钮文字、chip |
| labelMedium | 12 / 1.4 / 500 | 时间、计数、角标 |
| labelSmall | 11 / 1.4 / 500 | 极次要信息 |

- 进度时间格式：mm:ss（<1 小时）/ h:mm:ss（≥1 小时），与 intl 包一致。

### 2.3 间距与圆角（8pt 网格）

- 间距：4 / 8 / 12 / 16 / 20 / 24 / 32（页面左右安全边距统一 16）。
- 圆角：chip/开关 pill 999；按钮/输入框 12；列表卡片 16；对话框/底部菜单 20（顶部）。
- 触控热区：所有可点元素 ≥ 48×48 dp（进度条热区加高到 32dp 透明 padding）。

### 2.4 动效（只动 transform/opacity，保 165Hz 不掉帧）

| 场景 | 曲线 | 时长 |
| --- | --- | --- |
| 控制层显隐 | standard `cubic-bezier(0.2,0,0,1)` | 150ms |
| 滑动切换（跟随手指） | PageView 默认物理滚动 | — |
| 页面转场 | emphasized decelerate `cubic-bezier(0.05,0.7,0.1,1)` | 250ms |
| 对话框/底部菜单入场 | emphasized + scale 0.96→1 | 200ms |
| 收藏星标点击 | scale 1→1.25→1 + 金色填充 | 200ms |
| 下载进度刷新 | 直接 setState，禁动画（高频） | — |

## 3. 图标与空态

- 图标：Material Symbols Rounded（免费，与 M3 同语言；不用 emoji 当图标）。核心图标：play_arrow / pause / replay / forward / download / star / star_filled / more_horiz / folder / history / settings / wifi_off / error。
- 空态：大号线条图标（48dp，onSurfaceVariant）+ 一句人话 + （有下一步时）一个文字按钮。禁"什么都没有"四个字裸奔。

## 4. 页面规格

### 4.1 信息流播放页（首页，P0）

```
┌─────────────────────────┐
│ ▌scrimTop               │  ← 仅控制层显示时出现
│                         │
│       （视频全屏）        │
│                          │
│  ┌───────────────────┐  │  ← 长视频提示（仅 progress>0 且时长≥30min）：
│  │ 继续看 12:34      │  │  │ 「继续看 mm:ss」/「重头看」两枚 tonal 按钮
│  │ 重头看            │  │  │
│  └───────────────────┘  │
│                         │
│  ▶/⏸   ──●──  03:15/08:40 │  ← 控制层（点击屏幕显隐，3s 自动淡出）：
│  [1.0x] [⬇] [★] [⋯]     │  │ 播放/暂停 48dp；进度条+时间；倍速 chip；
│                         │  │ 下载/收藏/更多（⋯打开底部菜单）
└─────────────────────────┘
```

- 文件名浮层：控制层显示时，左上角 titleMedium 白色 + 文件夹名 labelMedium 70% 白。
- 状态：加载中（信息流底部细进度条）；加载失败（snackbar：「这条没加载上，滑走试试」+ 自动滑走）；离线（顶部横幅 F-20 文案 + 重试按钮）。
- 交互：上滑/下滑切随机视频（PageView 竖向，预加载下一首首段）；单击显隐控制层；双击播放区域 = 播放/暂停（热区避开按钮）。
- 验收要点：竖屏锁定；一屏一个视频无黑边；滑动 ≤500ms 起播；控制层不遮挡进度条热区。

### 4.2 连接页（P0）

个人自用模式：服务端默认不校验 token（`PcVideo:RequireToken=false`），**填地址就能连**，不逼用户找配对码。

- 结构：标题「连一下你的电脑」→ 地址输入（默认回填上次，placeholder `http://192.168.x.x:57821`）→ 主按钮「连接」。
- 配对码输入框**默认不显示**：只有服务端明确返回 401（用户自己在 appsettings 开了 RequireToken）时才展开。
- 连接逻辑：先探活 `GET /api/server/info`（公开接口）确认地址对，再直接进信息流；失败才显示错误。
- 错误文案：连接失败给三项检查引导——「① 电脑开机了吗？② 服务启动了吗？③ 同一个 WiFi 吗？」（F-20）。
- 验收要点：填对地址即可用；地址错误/服务未启动时提示可执行的下一步。

### 4.3 播放历史页（P1）

- 列表项：左侧缩略图占位（80×56dp，surfaceContainerHigh + 播放图标水印；P2 再上真缩略图）→ 右侧文件名 titleMedium（超长单行省略）+ 进度条 3dp + labelMedium「看到 12:34 / 44:00」或「看完了」徽标（primaryContainer 底）+ 右对齐上次时间 labelSmall。
- 操作：左滑露出「删除」（error 色）；顶部「清空」需二次确认对话框。
- 空态：history 图标 + 「还没看过片。回到首页刷几下，这里就有记录了。」

### 4.4 收藏列表页（P1）

- 结构同历史页；徽标换成 tertiary 金星 + 「已收藏」；列表项取消收藏用顶部编辑态或长按菜单（实现时二选一，架构师已定 W3-05）。
- 空态：star 图标 + 「看到喜欢的，点播放页里的星星，就会出现在这。」

### 4.5 文件夹管理页（P0，手机端只读 + 启停）

- 卡片：文件夹名 titleMedium + 路径 bodyMedium（onSurfaceVariant，超长中间省略）→ 右侧 M3 Switch（启停）→ 底部 labelMedium「128 个视频 · 2 个可能无法播放」。
- 停用中的卡片整体降不透明度 60% + 描边 outlineVariant。
- 顶部提示条：「加新文件夹、删文件夹，去电脑上的管理页面操作。」+ 地址回显（labelSmall，可点复制）。
- 验收：停一个文件夹，回信息流拉新随机池立即不含它的视频。

### 4.6 下载管理页（P1）

- 顶部分段按钮：「下载中 / 已完成」+ 右上角缓存用量 labelMedium（「已用 6.2 GB / 上限 10 GB」）。
- 下载中项：文件名 + 进度条（secondary 色）+ 百分比 + 暂停/恢复图标按钮 + 取消。
- 已完成项：文件名 + 大小 + 播放 + 删除；点击直接进信息流播本地文件。
- 达上限：顶部 error 色横幅「缓存满了，去设置里把上限调大，或清一清。」
- 空态：download 图标 + 「想把视频存到手机？播放页点下载。」

### 4.7 设置页（P1）

- 分组列表（surfaceContainer 卡片）：
  1. 服务器：服务名 + 地址 +「重新配对」入口；
  2. 播放：默认倍速（0.5–2.0 单选对话框）、自动连播开关；
  3. 下载：缓存上限（对话框输入 GB）、清理缓存（二次确认，显示将释放大小）；
  4. 关于：版本号、后台播放指引入口（ColorOS 电池优化白名单引导页）。
- 验收：设置改动即时生效；缓存清理后下载列表同步更新。

### 4.8 通用组件

- **底部菜单（app_menu_sheet）**：从底部滑入，圆角 20 顶部，6 个入口（历史/收藏/文件夹/下载/设置/重新配对），图标 + 文字横排两行或列表式（实现时任选，全 App 统一）。
- **按钮层级**：filled（主操作，primary 底白字）/ tonal（次操作，primaryContainer 底主色字）/ text（取消、重试）/ icon（控制层图标，48dp 热区）。
- **对话框**：危险操作（删除/清空）用 error 色确认键；确认式对话框（继续看/重头看）主键 tonal。
- **snackbar**：底部浮现，surfaceContainerHigh 底，3 秒，只传「出了什么事 + 该干嘛」。
- **加载**：局部用 3dp 细进度条；页面级用居中 CircularProgressIndicator（primary）。

## 5. 适配要点（一加 Ace 6 / Android 16 / ColorOS 16）

- 强制深色：`ThemeData(brightness: Brightness.dark)` 写死，不读系统设置。
- 165Hz：所有动画只用 transform/opacity；列表/PageView 内禁 backdropFilter 模糊；控制层渐变用预渲染渐变图或 shader，不用实时 blur。
- 6.83" 大屏：控制层按钮热区 ≥48dp；文件名浮层避让右上角（留 16dp + 状态栏高度）。
- 通知/锁屏媒体控制样式遵循 audio_service 默认 + 主色强调，不自定义复杂布局。
- 深浅色模式切换、平板、分屏：本期不适配（P2），布局降级可接受即可。

## 6. 文案规范（小白口吻，与 ARCHITECTURE §8.6 同源）

正例：
- 「连不上电脑。挨个看看：① 电脑开机了吗？② 服务启动了吗？③ 同一个 WiFi 吗？」
- 「配对码不对或过期了，看看电脑屏幕上的数字。」
- 「这条没加载上，滑走试试。」
- 「缓存满了，去设置里调大点，或清一清。」

反例（禁止）：
- 「尊敬的用户，检测到您的设备当前无法与服务器建立稳定连接呢~」
- 「全新引擎极速畅享，开启沉浸式观影之旅」
- 「错误代码：ERR_CONN_TIMEOUT_0x800C013B」（技术码必须翻译成人话）

规则：错误提示三要素（出了什么事 + 大概原因 + 下一步干嘛）；按钮动词化；同一概念全 App 叫法一致（"电脑"不混用"服务端/PC/主机"）。

## 7. Do / Don't

**Do**
- 深色表面用明度层次分层级（#0B0B0F → #14141A → #1F1F28）
- 动效短促（≤250ms），只表达状态变化
- 每个空态/错误态都给下一步
- 图标统一 Material Symbols Rounded

**Don't**
- 不用阴影堆叠表达层级（深色下脏）
- 不用彩虹渐变、不用超过 4 种彩色同屏
- 不用 emoji 替代图标
- 不在播放页放任何常驻边框/白底元素
- 不搞"下拉刷新""侧边栏"等本 App 不需要的手势

## 8. 验收清单（工程师自检 + QA 抽查）

| # | 检查项 |
| --- | --- |
| U1 | 全 App 深色，无白底白边；竖屏锁定 |
| U2 | 信息流一屏一视频，控制层点击显隐、3s 自动淡出 |
| U3 | 所有可点热区 ≥48dp；进度条热区加高 |
| U4 | 动效仅 transform/opacity；165Hz 下滑动无持续掉帧 |
| U5 | 空态/错误态/离线态均有文案与下一步 |
| U6 | 文案过 §6 正反例；无技术码直出 |
| U7 | 色彩同屏 ≤4 种；图标不混用风格 |
| U8 | 删除/清空类操作有二次确认 |
